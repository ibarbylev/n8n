## Первые шаги в n8n: инструкция для начинающих

Предположим, что n8n уже установлен через Docker и доступен по адресу `http://localhost:5678`.

Наша цель — познакомиться с интерфейсом и создать первый простой workflow (автоматизацию).

### 1. Первый вход

1. Откройте `http://localhost:5678`.
2. Создайте учётную запись администратора.
3. Заполните имя, email и пароль.
4. Войдите в систему.

После входа вы попадёте в основной интерфейс n8n.

### 2. Знакомство с интерфейсом

Основные понятия:

| Термин | Что означает |
|---|---|
| Workflow | Сценарий автоматизации |
| Node | Отдельный элемент сценария |
| Trigger | Событие, запускающее сценарий |
| Action | Действие, которое выполняет сценарий |
| Execution | Один запуск workflow |
| Credentials | Данные для подключения к внешним сервисам |

Например, автоматизация может выглядеть так:

```text
Получить новое письмо
        |
        v
Проверить содержание
        |
        v
Отправить уведомление в Telegram
```

Каждый прямоугольник — отдельная Node.

### 3. Создаём первый Workflow

Давайте сделаем простую автоматизацию: запуск по расписанию и получение текущей даты.

**Шаг 1.** Нажмите `Create Workflow`.

**Шаг 2.** Дайте сценарию название:

`Мой первый workflow`

**Шаг 3.** Добавьте первую Node.

Нажмите `Add first step` и найдите:

`Schedule Trigger`

Это триггер, который запускает автоматизацию по расписанию.

**Шаг 4.** Настройте расписание.

Например:
- Trigger Interval: Minutes
- Minutes Between Triggers: 5

Теперь сценарий будет запускаться каждые 5 минут после активации.

### 4. Добавляем вторую Node

Нажмите `+` справа от Schedule Trigger.

Найдите Node:

`Edit Fields (Set)`

Она позволяет создавать и изменять данные.

Добавьте поле:

| Параметр | Значение |
|---|---|
| Name | message |
| Type | String |
| Value | Привет! Это мой первый workflow в n8n |

Теперь ваша схема выглядит так:

```text
Schedule Trigger
       |
       v
Edit Fields
```

### 5. Проверяем работу

Для проверки:

1. Нажмите `Execute Workflow`.
2. Выберите Node `Edit Fields`.
3. Посмотрите результат выполнения во вкладке Output.

Вы должны увидеть:

```json
{
  "message": "Привет! Это мой первый workflow в n8n"
}
```

Поздравляю! Вы создали свою первую автоматизацию.

### 6. Сохраняем и активируем Workflow

1. Нажмите `Save`.
2. Переведите Workflow в состояние `Active` (в некоторых версиях интерфейса используется кнопка Publish).

Теперь n8n будет автоматически запускать сценарий каждые 5 минут.

Важно: расписание Schedule Trigger зависит от часового пояса, настроенного в n8n.

### Мой совет

Не пытайтесь сразу изучать все возможности n8n.

Лучше последовательно сделать три небольших проекта:

1. **Автоматизация по расписанию** — получать данные из открытого API.
2. **Telegram-бот** — принимать сообщения и отправлять ответы.
3. **AI-ассистент** — подключить языковую модель через API и научить её обрабатывать запросы.

После этих трёх проектов вы уже будете понимать основную логику n8n и сможете самостоятельно собирать достаточно сложные автоматизации.
